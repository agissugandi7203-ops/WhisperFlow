## Product Architecture

```
+──────────────────────────────────────────────────────────────────────────+
│                          WHISPERFLOW PIPELINE                            │
│                                                                          │
│  [Audio Ingress]  -->  [Aestra 2.1 Engine]  -->  [Pulse Diarization]    │
│   (16kHz/48kHz)         (< 28ms Latency)          (32 Concurrent Voices) │
│                                                         |                │
│                                                         v                │
│  [Zero-Data Vault] <-- [Semantic Reasoning] <-- [Token Stream]           │
│   (Ephemeral GPU)       (Action Registries)     (Real-Time PCM)          │
+──────────────────────────────────────────────────────────────────────────+
```

### Stage 01 — WebSocket PCM Ingestion
Stream 16kHz or 48kHz linear PCM directly over TLS WebSocket with zero client-side buffering and no codec transcoding overhead.

### Stage 02 — Acoustic Tokenization (Aestra 2.1 Sonic)
Proprietary streaming acoustic transformer decodes phonemes in sub-30ms frames with continuous speaker embedding updates across each audio packet.

### Stage 03 — Semantic Structuring
Real-time extraction of action items, decision registries, consensus votes, ownership attributions, and structured meeting artifacts.

### Stage 04 — Zero-Retention Sovereign Vault
Raw audio buffers are cryptographically purged from GPU memory immediately upon completion of token streaming. Zero residue, zero exposure.

|---|---|---|---|

## Getting Started

### Prerequisites
- Node.js `v18.0.0` or higher
- npm `v9.0.0` or higher

### Installation

```bash
git clone https://github.com/agissugandi7203-ops/WhisperFlow.git
cd WhisperFlow
npm install --legacy-peer-deps
```

### Development

```bash
npm run dev
# Open http://localhost:5173
```

### Production Build

```bash
npm run build
npm run preview
```

## Deployment

### Railway (Recommended)

1. Connect your GitHub repo at [railway.app](https://railway.app) → New Project → Deploy from GitHub
2. Select `agissugandi7203-ops/WhisperFlow`
3. Railway auto-detects Vite. Confirm settings:
   - **Build Command**: `npm run build`
   - **Start Command**: `npm run start`
4. Deploy — Railway generates a public URL automatically.

The `start` script in `package.json` is pre-configured to bind `0.0.0.0` and read Railway's dynamic `$PORT`:

```json
"start": "vite preview --host 0.0.0.0 --port ${PORT:-5173}"
```

### Vercel / Netlify

Both platforms support Vite out of the box. Set:
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
